# Pesquisa e importação

Esta pasta reúne páginas HTML salvas das fontes, registros de pesquisa, evidências e scripts usados para conferir e importar os gols. Não faz parte da interface pública: o servidor serve somente `public/`.

As páginas salvas permitem revisar a classificação sem perder a evidência original. Os scripts podem depender dos caminhos atuais; por isso os arquivos foram preservados aqui.

Os dados consolidados e a descrição dos critérios ficam em `database/`. Antes de rodar importações, consulte `database/DADOS.md` e o script correspondente. Alguns scripts alteram o banco.
